    Knowledge Base

    A plain-English glossary of 434 terms across web development, web design, SEO, SaaS and AI.

    Knowledge Base

    Technology conversations are full of jargon. This knowledge base from Tenshi Systems Engineering, a web and software company in Madison, Wisconsin, explains the words you will meet when planning, building, promoting and running a website or online product.

    Each entry gives a short definition, and where it helps, a line on why it matters for your business, plus related terms to explore. Definitions are general and evergreen; for legal or compliance topics such as GDPR, APPI, PCI DSS or SOC 2, take professional advice for your situation.

    Web Development

    101 terms

    Agile

    Web Development

    A way of running software projects in short cycles, delivering working pieces often and adjusting based on feedback rather than fixing every detail up front.

    Why it matters for your business: You see progress early and can change priorities without restarting the project.

    See also: SprintBacklogMVP (Minimum Viable Product)

    API (Application Programming Interface)

    Web Development

    A set of rules that lets one piece of software ask another for data or actions. When your website shows a map, takes a card payment or pulls in reviews, it is usually talking to another service through an API.

    Why it matters for your business: APIs let you connect tools you already pay for instead of rebuilding them.

    See also: REST APIWebhookIntegrationSDK (Software Development Kit)

    Asynchronous (async)

    Web Development

    Code that starts a task, such as loading data, and carries on with other work instead of waiting for it to finish.

    Why it matters for your business: Async code keeps pages responsive while slower tasks run in the background.

    See also: JavaScriptAPI (Application Programming Interface)

    Authentication

    Web Development

    Checking who someone is, usually with a password, a code or a passkey, before letting them in.

    Why it matters for your business: Strong sign-in protects customer accounts and your admin areas.

    See also: AuthorizationTwo-factor authentication (2FA)Single sign-on (SSO)

    Authorization

    Web Development

    Deciding what a signed-in person is allowed to see or do, such as whether they can edit pages or only view them.

    Why it matters for your business: Limits the damage if one account is misused.

    See also: AuthenticationRole-based access control (RBAC)

    Back end

    Web Development

    The part of a website or app that runs on the server: databases, business logic, user accounts and anything the visitor does not see directly.

    See also: Front endFull stackServerDatabase

    Backup

    Web Development

    A saved copy of your site files and database that can be restored if something breaks, is hacked or is deleted by mistake.

    Why it matters for your business: A tested, recent backup is the difference between a bad afternoon and losing your site.

    See also: RollbackDisaster recovery

    Browser

    Web Development

    The program people use to view websites, such as Chrome, Safari, Edge or Firefox. Each one displays code slightly differently, so sites are tested in several.

    See also: HTML (HyperText Markup Language)Cross-browser testing

    Bug

    Web Development

    A mistake in code that makes software behave in a way nobody intended.

    See also: DebuggingTesting

    Build

    Web Development

    The step that turns source code into the optimized files that are actually served to visitors, often bundling, minifying and checking the code along the way.

    See also: DeploymentMinificationCI/CD

    Cache

    Web Development

    A stored copy of data or pages kept close at hand so they can be served faster the next time, without redoing the work.

    Why it matters for your business: Good caching makes sites feel fast and lowers hosting load. Stale caches are also why changes sometimes do not show up right away.

    See also: CDN (Content Delivery Network)Page speed

    CDN (Content Delivery Network)

    Web Development

    A network of servers around the world that stores copies of your site's files and serves each visitor from a nearby location.

    Why it matters for your business: Faster loading for visitors far from your main server, plus extra protection against traffic spikes.

    See also: CacheHostingEdge computing

    CI/CD

    Web Development

    Continuous Integration and Continuous Delivery or Deployment: automated steps that test and release code every time a change is made.

    Why it matters for your business: Fewer manual mistakes and quicker, safer updates.

    See also: BuildDeploymentTestingGit

    CLI (Command-Line Interface)

    Web Development

    A text-based way to control software by typing commands instead of clicking buttons.

    See also: Package manager

    Client-side rendering

    Web Development

    Building a page in the visitor's browser with JavaScript after the initial download, rather than on the server.

    Why it matters for your business: Can feel app-like, but if done carelessly it can slow first loads and make content harder for search engines to read.

    See also: Server-side rendering (SSR)Single-page application (SPA)JavaScript

    Code review

    Web Development

    A teammate reading proposed code changes before they go live to catch bugs, security issues and confusing code.

    See also: Pull requestVersion control

    Container

    Web Development

    A lightweight package that bundles an application with everything it needs to run, so it behaves the same on a laptop, a test server and production. Docker is the best-known tool.

    See also: DockerServerDeployment

    Content management system (CMS)

    Web Development

    Software that lets non-developers create and edit website content through an admin screen.

    Why it matters for your business: Your team can update the site without calling a developer for every change.

    See also: WordPressHeadless CMS

    Cookie

    Web Development

    A small piece of data a website stores in the browser to remember things like a login, a cart or preferences.

    Why it matters for your business: Some cookies need visitor consent under privacy laws, so your site may need a consent banner.

    See also: SessionGDPR

    CORS (Cross-Origin Resource Sharing)

    Web Development

    A browser security rule that controls which other websites are allowed to request data from your server.

    See also: API (Application Programming Interface)Browser

    Cron job

    Web Development

    A task scheduled to run automatically at set times, such as a nightly backup or a weekly report.

    See also: ServerBackup

    Cross-browser testing

    Web Development

    Checking that a site looks and works correctly across different browsers and devices.

    See also: BrowserResponsive design

    CRUD

    Web Development

    Create, Read, Update, Delete: the four basic things most apps do with data.

    See also: DatabaseAPI (Application Programming Interface)

    CSS (Cascading Style Sheets)

    Web Development

    The language that controls how web pages look: colors, fonts, spacing and layout.

    See also: HTML (HyperText Markup Language)Responsive designTypography

    Database

    Web Development

    An organized store of information, such as products, orders or users, that an app can search and update quickly.

    See also: SQLBack endCRUD

    Debugging

    Web Development

    Finding and fixing the cause of a bug.

    See also: BugTesting

    Dependency

    Web Development

    An outside library or package your code relies on.

    Why it matters for your business: Outdated dependencies are a common source of security holes, so they need regular updates.

    See also: LibraryPackage managerTechnical debt

    Deployment

    Web Development

    Putting a new version of a site or app live on a server so people can use it.

    See also: CI/CDStaging environmentRollback

    Disaster recovery

    Web Development

    The plan and tools for getting systems running again after a serious failure, attack or data loss.

    Why it matters for your business: Knowing how long recovery takes helps you judge how much downtime you can live with.

    See also: BackupUptimeService level agreement (SLA)

    DNS (Domain Name System)

    Web Development

    The internet's address book. It turns a domain like example.com into the numeric address of the server that hosts it.

    Why it matters for your business: DNS settings control where your website and email go, so mistakes here can take both offline.

    See also: Domain nameHostingSSL/TLS certificate

    Docker

    Web Development

    A popular tool for creating and running containers.

    See also: Container

    DOM (Document Object Model)

    Web Development

    The browser's live, structured model of a web page, which JavaScript reads and changes to update what you see.

    See also: HTML (HyperText Markup Language)JavaScript

    Domain name

    Web Development

    The human-readable address of a website, such as tenshi.example. You rent it yearly from a registrar.

    Why it matters for your business: Register it in your company's name and turn on auto-renew so it cannot lapse.

    See also: DNS (Domain Name System)Hosting

    Edge computing

    Web Development

    Running code on servers close to the visitor, often inside a CDN, instead of in one central data center.

    Why it matters for your business: Lower delay for visitors spread across regions.

    See also: CDN (Content Delivery Network)Serverless

    Encryption

    Web Development

    Scrambling data so only someone with the right key can read it. HTTPS encrypts data in transit; disk or database encryption protects data at rest.

    See also: HTTPSSSL/TLS certificate

    Environment variables

    Web Development

    Settings, such as API keys or database addresses, kept outside the code so they can differ between test and live systems and stay out of public view.

    Why it matters for your business: Keeps secrets out of your code repository.

    See also: Staging environmentAPI (Application Programming Interface)

    Firewall

    Web Development

    A filter that blocks unwanted network traffic. A web application firewall (WAF) specifically screens website requests for common attacks.

    See also: Security patchRate limiting

    Framework

    Web Development

    A ready-made structure and toolkit for building software, such as React-based Next.js, Laravel or Django, so developers do not start from scratch.

    See also: LibraryReact

    Front end

    Web Development

    Everything visitors see and interact with in the browser: layout, buttons, forms and animations.

    See also: Back endHTML (HyperText Markup Language)CSS (Cascading Style Sheets)JavaScript

    Full stack

    Web Development

    Work, or a developer, covering both the front end and the back end.

    See also: Front endBack end

    Git

    Web Development

    The most widely used version control system. It records every change to code and lets teams work on the same project safely.

    See also: Version controlRepositoryGitHub

    GitHub

    Web Development

    A website for hosting Git repositories, reviewing code and running automation. It can also host simple static websites.

    See also: GitRepositoryPull request

    GraphQL

    Web Development

    A way of building APIs where the app asks for exactly the fields it needs in one request.

    See also: API (Application Programming Interface)REST API

    Headless CMS

    Web Development

    A content management system that stores and edits content but leaves the display to a separate front end, connected through an API.

    Why it matters for your business: Lets you reuse the same content on a website, an app and elsewhere.

    See also: Content management system (CMS)API (Application Programming Interface)Jamstack

    Hosting

    Web Development

    Renting space on a server so your website is available on the internet around the clock.

    See also: ServerVPS (Virtual Private Server)UptimeDomain name

    HTML (HyperText Markup Language)

    Web Development

    The language that structures web page content into headings, paragraphs, links, images and forms.

    See also: CSS (Cascading Style Sheets)DOM (Document Object Model)

    HTTP

    Web Development

    The protocol browsers and servers use to request and send web pages.

    See also: HTTPSStatus code

    HTTPS

    Web Development

    The secure, encrypted version of HTTP, shown by the padlock in the browser.

    Why it matters for your business: Browsers warn visitors about sites without it, and it protects any data people send you.

    See also: SSL/TLS certificateEncryption

    IDE (Integrated Development Environment)

    Web Development

    A code editor with built-in tools for writing, running and debugging code.

    See also: Debugging

    Jamstack

    Web Development

    An approach that serves pre-built pages from a CDN and adds dynamic features through JavaScript and APIs.

    Why it matters for your business: Often fast, secure and cheap to host.

    See also: Static siteHeadless CMSCDN (Content Delivery Network)

    JavaScript

    Web Development

    The programming language that runs in web browsers and makes pages interactive. It also runs on servers through Node.js.

    See also: TypeScriptNode.jsFront end

    JSON

    Web Development

    A simple text format for structured data that is easy for both people and programs to read. Most APIs send data as JSON.

    See also: API (Application Programming Interface)

    Lazy loading

    Web Development

    Waiting to load images or other content until the visitor is about to scroll to them.

    Why it matters for your business: Speeds up the first view of a page.

    See also: Page speedImage optimization

    Library

    Web Development

    A collection of ready-made code for a specific job, such as handling dates or drawing charts, that developers plug into a project.

    See also: FrameworkDependency

    Load balancer

    Web Development

    A system that spreads incoming traffic across several servers so no single one is overwhelmed.

    See also: ScalabilityServer

    Localhost

    Web Development

    A developer's own computer acting as a private web server for building and testing before anything goes live.

    See also: Staging environment

    Microservices

    Web Development

    An architecture where an app is split into many small, independent services that talk to each other through APIs.

    Why it matters for your business: Can help large systems scale, but adds complexity most small projects do not need.

    See also: API (Application Programming Interface)Monolith

    Middleware

    Web Development

    Software that sits between parts of a system, such as checking logins or logging requests before they reach the main app.

    See also: Back end

    Minification

    Web Development

    Removing spaces, comments and long names from code files to make them smaller and faster to download.

    See also: BuildPage speed

    Monolith

    Web Development

    An app built and deployed as one single unit. Simpler to run than microservices and often the right choice for small teams.

    See also: Microservices

    MVP (Minimum Viable Product)

    Web Development

    The simplest version of a product that solves the core problem well enough to test with real users.

    Why it matters for your business: Lets you learn what customers want before spending heavily.

    See also: AgileProduct-market fit

    Node.js

    Web Development

    A runtime that lets JavaScript run on servers, widely used for back ends and developer tooling.

    See also: JavaScriptBack endPackage manager

    Open source

    Web Development

    Software whose source code is public and can be used, changed and shared under its license.

    Why it matters for your business: Can lower costs, but check the license and that the project is actively maintained.

    See also: LibraryWordPress

    ORM (Object-Relational Mapping)

    Web Development

    A tool that lets developers work with database records as normal code objects instead of writing raw SQL.

    See also: DatabaseSQL

    Package manager

    Web Development

    A tool, such as npm, that installs and updates the libraries a project depends on.

    See also: DependencyLibrary

    PHP

    Web Development

    A server-side programming language that powers WordPress and many other websites.

    See also: WordPressBack end

    Progressive Web App (PWA)

    Web Development

    A website that behaves like an app: it can be installed on a home screen, load quickly and sometimes work offline.

    Why it matters for your business: App-like convenience without app store fees or separate builds.

    See also: Service workerResponsive design

    Pull request

    Web Development

    A proposed set of code changes submitted for review before being merged into the main code.

    See also: Code reviewGitGitHub

    Python

    Web Development

    A readable, general-purpose programming language popular for back ends, automation, data work and AI.

    See also: Back endMachine learning

    Rate limiting

    Web Development

    Capping how many requests someone can make in a set time, to stop abuse and keep a service stable.

    React

    Web Development

    Repository

    Web Development

    The storage place for a project's code and its full change history.

    REST API

    Web Development

    A common style of API that uses standard web addresses and HTTP methods to read and change data.

    Rollback

    Web Development

    SDK (Software Development Kit)

    Security patch

    Web Development

    An update that fixes a known security weakness in software.

    Server

    Server-side rendering (SSR)

    Web Development

    Building the full page on the server before sending it, so visitors and search engines receive ready-to-read content.

    Serverless

    Web Development

    Running code on a cloud provider's infrastructure that starts on demand, so you do not manage servers yourself and usually pay only for what you use.

    Service worker

    Session

    A temporary record that keeps a visitor signed in or remembers their cart as they move between pages.

    Single-page application (SPA)

    Web Development

    A website that loads once and then updates content in place as you click, without full page reloads.

    See also: Client-side renderingReact

    SQL

    Web Development

    Structured Query Language, the standard language for asking questions of and updating relational databases.

    SSL/TLS certificate

    Web Development

    A digital certificate that proves your site's identity and enables HTTPS encryption. TLS is the modern successor to SSL, though both names are used.

    Why it matters for your business: Needed for the browser padlock; many hosts provide free certificates that renew automatically.

    Static site

    Web Development

    A website made of pre-built files served the same way to every visitor, without a database building each page on request.

    Web Development

    Status code

    Web Development

    Technical debt

    Web Development

    The future cost of shortcuts taken in code today, which make later changes slower and riskier.

    Why it matters for your business: Some debt is fine, but unmanaged debt makes every new feature cost more.

    Testing

    Web Development

    Checking that software works as intended, often with automated tests that run on every change. Unit tests check small pieces; end-to-end tests check whole user journeys.

    See also: BugCI/CD

    Two-factor authentication (2FA)

    Web Development

    Signing in with a second proof, such as a code from an app, in addition to a password.

    See also: AuthenticationMulti-factor authentication (MFA)

    The small icon shown in the browser tab, bookmarks and sometimes search results.

    Figma

    Web Design

    A popular browser-based tool for designing interfaces, wireframes and prototypes collaboratively.

    Flat design

    A clean style that avoids heavy shadows, textures and 3D effects in favor of simple shapes and color.

    Choosing typefaces that work well together, often one for headings and another for body text.
