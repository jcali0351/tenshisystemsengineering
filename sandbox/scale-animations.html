Endless scale animations

Five techniques, each growing and shrinking forever. Hover a card to pause it.

1. Pure CSS

@keyframes with infinite alternate. Simplest, and the browser does all the work.

2. Web Animations API

element.animate() with iterations: Infinity. CSS speed, JavaScript control.

3. requestAnimationFrame

A sine wave worked out every frame. Full control over every moment.

4. Staggered wave

25 dots, each starting a little later, so a ripple runs across them.

5. Heartbeat

Several keyframes for a beat-beat-rest rhythm instead of a smooth swing.
