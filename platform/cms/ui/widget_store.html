Connect your Shopify store

About ten minutes, in your Shopify admin. You need a Shopify plan that can sell (development stores only take test orders).

  1. Install the Headless channel. Shopify admin › Sales channels › + (or the Shopify App Store) › search Headless › Add sales channel. It's free and made by Shopify.
  2. Create a storefront. Headless › Create storefront.
  3. Set its permissions. The storefront › Storefront API › Manage next to permissions: tick unauthenticated_read_product_listings, unauthenticated_write_checkouts and unauthenticated_read_checkouts (optional: unauthenticated_read_product_inventory). Save.
  4. Copy the PUBLIC access token from the same page and paste it here. Never the private access token or an Admin API token (shpat_…): those are passwords to your store and this form refuses them.
  5. Find your .myshopify.com address. Settings › Domains shows it (like your-store.myshopify.com). Paste it under Store address.
  6. Publish products to Headless. Products › select them › More actions › Include in sales channels › Headless. Products not on the channel don't show.
  7. Optional: make a collection and put its handle (the end of its address, like summer-sale) above or in a Store block.
  8. Choose Live, Save, and Publish the site.

Payments, taxes, shipping and order emails stay in Shopify. Your site only shows products and hands the cart to Shopify's checkout.
