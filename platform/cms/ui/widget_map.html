Get a Google Maps key

  1. Open console.cloud.google.com, sign in and create a project (or pick one). Google asks for a billing account; small sites usually stay inside the free monthly credit.
  2. APIs & Services › Library: enable Maps JavaScript API and Geocoding API (Geocoding finds places you typed without coordinates).
  3. APIs & Services › Credentials › Create credentials › API key.
  4. Restrict the key. Application restrictions › Websites: add https://{{ site.subdomain }}.{{ sites_domain }}/* and your own domain (for example https://www.example.com/*). API restrictions: the two APIs above.
  5. Paste the key here and Save, then Publish.

If Google refuses the key (not enabled, wrong address), visitors still see the standard map.
