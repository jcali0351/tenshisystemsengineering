Tenshi Editor

Sign in to edit the site

The site lives on GitHub, so a GitHub key is your login. Everything you save goes to the live site, which updates about a minute later.

How do I get a GitHub key?
  1. Open github.com › Settings › Fine-grained tokens › Generate new token.
  2. Name it Tenshi Editor and pick an expiry (90 days is a good balance).
  3. Repository access: Only select repositories › tenshisystemsengineering.
  4. Permissions › Repository permissions › Contents: Read and write. Nothing else is needed.
  5. Generate the token, copy it and paste it above. GitHub shows it only once.

The key stays in this browser. It's never saved in the website's files.

Click any text or picture on the page to change it. Links don't open while you edit.

    Click a picture to replace it. New pictures are resized and compressed in your browser before they're saved.

        Tenshi Blog Writer Blog

        Reads the week's news about web design, software, AI and technology in Japan, then writes new posts in Tenshi's voice, in its own words. Each post lists and links the reports it used, says it was written with AI help, and gets a free-to-use feature photo with its credit. The first run also removes the placeholder posts.

        Needs an Anthropic API key saved on GitHub as the secret ANTHROPIC_API_KEY (add it here). With the key, the Scraper also writes a one-line summary for each story.
