Tenshi Editor

Sign in to edit the site

The site lives on GitHub, so a GitHub key is your login. Everything you save goes to the live site, which updates about a minute later.

How do I get a GitHub key?
  1. Open github.com › Settings › Fine-grained tokens › Generate new token.
  2. Name it Tenshi Editor and pick an expiry (90 days is a good balance).
  3. Repository access: Only select repositories › tenshisystemsengineering.
  4. Permissions › Repository permissions › Contents: Read and write. Nothing else is needed.
  5. Generate the token, copy it and paste it above. GitHub shows it only once.

The key stays in this browser. It's never saved in the website's files.

        How Custom CSS works

        Rules you write here are saved to custom.css, which every page loads last, after all the site's own styles and the Buttons settings. When two rules are equally specific, yours win; to beat a stubborn rule add !important, e.g. .site-footer { background: #111 !important; }. Paths in url() start from the site's main folder, e.g. url(img/photos/kobe.jpg).

        Only CSS goes here (no <style> or <script> tags). Tab inserts two spaces; press Esc, then Tab, to move on. The preview below applies your CSS as you type; Save puts it on the site. Clear the box to remove all custom styles.
